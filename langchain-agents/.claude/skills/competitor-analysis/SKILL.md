# Competitor Analysis Skill

Systematic approach to gathering and analyzing competitive intelligence.

## Analysis Framework

### Phase 1: Competitor Identification
List competitors you're analyzing:
- Direct competitors (similar product/market)
- Indirect competitors (alternative solutions)
- Market leaders
- Emerging challengers

### Phase 2: Feature Extraction
For each competitor, document:
```
Product: [Name]
Website: [URL]

Core Features:
- Feature 1
- Feature 2
- Feature 3

Unique Strengths:
- Strength 1
- Strength 2

Differentiators:
- What sets them apart
```

### Phase 3: Pricing Analysis
```
Tier          | Price      | Key Features
Free/Starter  | $X/month   | [list features]
Pro           | $Y/month   | [list features]
Enterprise    | Custom     | [custom features]

Pricing Model: Seat-based, usage-based, feature-based
Contract Terms: Monthly, annual, custom
```

### Phase 4: Market Positioning
- **Target Market**: Who are they selling to?
- **Value Proposition**: Their core selling point
- **Brand Positioning**: How they market themselves
- **Market Share Indicators**: If available

### Phase 5: Competitive Advantages Analysis
For your/reference product:
```
Competitive Advantages:
✓ [Advantage 1] - vs competitors lacking this
✓ [Advantage 2] - where we excel
✗ [Disadvantage 1] - where they beat us
✗ [Disadvantage 2] - gap we need to close
```

### Phase 6: Market Trends
- Recent product updates/launches
- Funding rounds or acquisition activity
- Market growth indicators
- Emerging use cases

## Data Collection Methods

### Website Analysis
- Visit competitor sites
- Extract: pricing, features, positioning
- Look for: recent news, case studies, testimonials

### News & Updates
- Search for recent announcements
- Check company blogs
- Monitor press releases
- Track funding/M&A activity

### Feature Comparison
```bash
# Create structured comparison table
Product A | Product B | Product C
---------|----------|----------
Feature 1|    ✓     |    ✓    |   ✗
Feature 2|    ✓     |    ✗    |   ✓
Feature 3|    ✗     |    ✓    |   ✓
```

### Pricing Comparison
- List-price vs negotiated
- Free tier availability
- Trial periods
- Volume discounts

## Output Structure

### Executive Summary
- Number of competitors analyzed
- Top 2-3 market leaders
- Key market trends
- Primary gap/opportunity

### Competitive Matrix
Create visual comparison showing:
- Price ranges
- Feature coverage
- Market positioning
- Key differentiators

### Detailed Findings
For each competitor:
- Company overview
- Product positioning
- Feature set
- Pricing model
- Strengths vs weaknesses
- Recent activity/news

### Strategic Insights
- Market consolidation patterns
- Emerging competitive threats
- Underserved market segments
- Technology/feature trends

## Quality Checklist

- ✅ 3+ competitors analyzed
- ✅ Data from official sources (websites, docs)
- ✅ Pricing current/dated
- ✅ Features verified from product
- ✅ Recent news included (last 30-90 days)
- ✅ Clear advantage/disadvantage identification
- ✅ Market position justified with evidence

## When to Use This Skill

- ✅ Evaluating market positioning
- ✅ Understanding competitive landscape
- ✅ Planning product features
- ✅ Pricing strategy research
- ✅ Sales/marketing intelligence
- ❌ Not for scraping private pricing (unethical)
- ❌ Not for competitive espionage
