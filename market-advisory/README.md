# Market Advisory — Daily Run Logs

This directory stores daily market advisory reports generated by the AI financial analysis routine.

## Structure

```
market-advisory/
  README.md              # This file
  logs/
    2026-06-26.md        # Daily log — one file per trading day
    2026-06-27.md
    ...
```

## Log Format

Each daily log contains:
- **Macro Snapshot** — Treasury yields, CPI, PCE, oil, VIX, Fed rate
- **Macro Environment Gate** — Risk gate check (3 conditions)
- **Top News Events** — Market-moving events from past 24 hours
- **Open Recommendations Check** — Validation of prior session's calls
- **Portfolio Analysis** — Per-stock recommendation (BUY NOW / ACCUMULATE / WATCHLIST / WAIT)
- **Proactive Suggestions** — Opportunities outside the portfolio
- **Key Calendar** — Events in the next 7 days
- **Action Summary** — Exact DO / DO NOT / WAIT instructions

## File Naming

Files are named `YYYY-MM-DD.md` using the trading day date (ET timezone).
Weekends and market holidays are skipped.

## Usage by the Routine

The daily routine reads the **last 7 calendar days** of logs (typically 5 trading days) to:
1. Track open recommendations and validate/invalidate them
2. Detect trend changes (e.g., yield direction, stock price movement)
3. Avoid contradicting recent calls without explicit reasoning
4. Provide continuity in position sizing (don't re-recommend full entry if partial already suggested)
